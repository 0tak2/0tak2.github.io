# 검은 CRT 비디오 신시사이징 화면 설계

## 목표

첫 화면의 TV는 제목 오른쪽이라는 현재 레이아웃을 유지한다. 본체를 무광 검정 CRT로 바꾸고, 왼쪽으로 치우친 유리 화면을 본체의 가로축 정중앙에 배치한다. 화면에는 백남준의 비디오 아트에서 영감을 받은 화려한 비디오 신시사이징 모션을 코드 뒤에 렌더링한다.

특정 작품을 복제하지 않는다. 강한 색채, 아날로그 영상 피드백, CRT의 색 번짐과 주사선이라는 시각 언어만 사용한다.

## TV 본체와 화면 배치

- TV는 첫 화면의 오른쪽 열에 유지한다. 제목과 TV의 두 열 레이아웃을 변경하지 않는다.
- 본체는 페이지의 검정 토큰과 같은 `#0b0b0b` 계열의 무광 재질을 사용한다. 순수 검정 `#000000`은 사용하지 않는다.
- 현재 90년대 한국 가정용 CRT의 낮고 두꺼운 사각 실루엣, 하단 버튼과 측면 스피커는 유지한다.
- 안테나, 다리와 상단 다이얼은 추가하지 않는다.
- 유리 화면의 가로 중심은 본체의 기하학적 중심인 `x = 0`에 둔다. 왼쪽과 오른쪽 베젤 여백은 대칭이어야 한다.
- 화면 아래의 물리 버튼 공간은 유지하므로 유리의 세로 위치는 현재 하단 조작부와 겹치지 않는 범위에서만 조정한다.
- 캔버스와 카메라 거리는 현재의 잘림 방지 값을 유지한다.

## 비디오 신시사이징 화면

CanvasTexture는 한 장의 정적 그림이 아니라 시간에 따라 갱신되는 화면으로 변경한다.

1. 마젠타, 시안, 옐로, 블루의 큰 컬러 필드가 서로 다른 속도와 궤적으로 이동한다.
2. 반투명한 이전 프레임을 남겨 화면 안쪽으로 이어지는 아날로그 피드백 잔상을 만든다.
3. 짧고 약한 RGB 채널 분리와 수평 흔들림을 간헐적으로 더한다.
4. CRT 주사선과 미세한 노이즈를 마지막 레이어에 올린다.
5. 기존 코드는 가장 위에 렌더링한다. 완전한 가독성보다 코드의 존재가 인식되는 정도를 목표로 한다.

색상 변화는 무작위 값만 누적하지 않고 경과 시간을 입력으로 계산한다. 같은 시간에는 같은 프레임 파라미터가 나와 테스트할 수 있어야 하며, 장시간 실행해도 색상이나 좌표 값이 범위를 벗어나지 않아야 한다.

## 렌더링 구조와 성능

- `scripts/tv-screen-motion.js`는 경과 시간을 받아 컬러 필드 위치, 크기, 색상 변화, 글리치 강도를 반환하는 순수 계산만 담당한다.
- `scripts/tv-scene.js`는 계산 결과를 Canvas 2D에 그려 CanvasTexture를 갱신하고 Three.js 화면 재질에 사용한다.
- 화면이 뷰포트에 있을 때만 애니메이션을 진행한다.
- 프레임 사이에 최소 `33ms`를 두어 최대 약 30fps로 제한한다. 화면 텍스처가 갱신된 프레임에만 Three.js 장면을 다시 렌더링한다.
- 장면을 파괴할 때 애니메이션 프레임과 CanvasTexture를 함께 정리한다.
- `prefers-reduced-motion: reduce`에서는 첫 프레임만 그린 뒤 정지한다.
- WebGL을 사용할 수 없을 때의 CSS 대체 TV도 검은 본체와 다색 그라데이션 화면을 사용한다. 모션 감소 설정에서는 CSS 그라데이션도 정지한다.

## 이름 정렬

- `임영택`과 `YOUNGTAEK LIM`은 같은 행에 둔다.
- `YOUNGTAEK LIM`은 `임영택`의 오른쪽 위에 작은 윗첨자처럼 배치한다. 별도 줄로 내리지 않는다.
- 한국어 이름은 기존 `700` Bold를 유지하고 영문 이름은 기존 monospace와 `500` Medium을 유지한다.
- 한국어 글리프가 가진 왼쪽 사이드베어링 때문에 제목보다 오른쪽에서 시작하는 문제는 `.hero__name`에 `margin-left: -0.04em`을 적용해 보정한다.
- 영문 이름은 `margin-left: 0.65rem`과 `transform: translateY(-0.25em)`을 사용한다.
- 모바일에서도 두 이름을 같은 행에 유지하되 화면 밖으로 넘치지 않도록 현재 반응형 글자 크기를 유지한다.

## 접근성과 기존 수정 사항

- TV의 접근 가능한 설명은 코드와 컬러 영상이 표시되는 3D 브라운관임을 반영한다.
- 강한 모션은 모션 감소 설정을 존중한다.
- GPS 위치정보 제거, 모바일 첫 화면 높이, 순택이 모바일 겹침, 키보드 오버레이 이동, BFCache 복원과 링크 터치 영역에 대한 최종 리뷰 수정은 그대로 진행한다.
- 사진의 GPS 이외 EXIF 정보는 제거하지 않는다.

## 교육 콘텐츠 보정

- Apple Developer Academy 학습 기술 목록을 `SwiftUI, Swift Data, ARKit, RealityKit, AVFoundation`으로 변경한다.
- 나머지 교육 문구와 App Store 링크는 유지한다.

## 검증 기준

- TV는 제목 오른쪽 열에 남아 있다.
- 본체가 `#0b0b0b` 계열의 검정이며 유리 화면의 가로 중심이 `x = 0`이다.
- 화면 뒤에서 네 가지 계열의 컬러 필드와 피드백·글리치·주사선이 움직인다.
- 코드가 컬러 모션 위에 남아 있어 코드 화면임을 인식할 수 있다.
- 화면이 보이지 않을 때 텍스처 애니메이션이 중지된다.
- 모션 감소 환경과 WebGL 실패 환경에서 정적 대체 화면이 보인다.
- `임영택`과 `YOUNGTAEK LIM`이 한 행에 있고 영문 이름이 오른쪽 위에 놓인다.
- 한국어 이름과 메인 제목의 왼쪽 시작선이 시각적으로 맞는다.
- Apple Developer Academy 기술 목록에 `AVFoundation`이 표시된다.
- 기존 전체 테스트와 새 화면 모션 계산 테스트가 통과한다.
