# 포트폴리오 타이포그래피 후속 보정 설계

## 목표

첫 화면의 글자 사이와 줄 사이에 더 많은 여백을 주고, 페이지 배경에서 느껴지는 누런 기운을 제거한다. [일민미술관](https://ilmin.org/)의 흰 배경과 여백 중심 구성을 참고하되 현재 포트폴리오의 콘텐츠, 선, 3D TV와 오버레이 구조는 유지한다.

## 배경과 색상

- 페이지 배경 변수 `--paper`를 중성 화이트 `#fefefe`로 변경한다.
- 기존 요청에 따라 순수 흰색 `#ffffff`와 순수 검정 `#000000`은 사용하지 않는다.
- 본문색 `#0b0b0b`, 선 색상과 TV 색상은 유지한다.
- 베이지나 따뜻한 회색을 새로 추가하지 않는다.

## 첫 화면 타이포그래피

- 이름은 `font-weight: 700`, `line-height: 1.2`, `letter-spacing: -0.01em`으로 조정한다.
- 영문 이름은 현재 monospace를 유지하고 자간을 `0.09em`으로 넓힌다.
- 메인 문장 `상상을 컴파일하는 엔지니어.`는 `font-weight: 700`, `line-height: 1.25`, `letter-spacing: -0.01em`으로 조정한다.
- 설명 문장은 `font-weight: 400`, `line-height: 2`, `letter-spacing: 0`으로 조정한다.
- 상단 외부 링크는 현재 크기와 monospace를 유지하고 자간을 `0.055em`으로 넓힌다.
- 첫 화면의 텍스트 크기, 문구, 열 구성과 TV 위치는 변경하지 않는다.

## 글자 굵기 원칙

전체 페이지에서 엑스트라볼드 계열을 사용하지 않는다.

- 허용 범위는 `300` Light, `400` Regular, `500` Medium, `700` Bold다.
- 기존 `760`, `800`, `830`, `850`처럼 `700`을 초과하는 값을 모두 `700` 이하로 낮춘다.
- 이름, 메인 문장, 섹션 제목, 회사명은 필요한 경우에만 `700`을 사용한다.
- 본문과 설명은 `400`, 보조 정보는 `300` 또는 `500`을 사용한다.
- 시각적 위계는 과도한 굵기 대신 크기, 여백, 자간과 얇은 선으로 만든다.

## Contact Me 오버레이

- 기본 너비를 `18rem`에서 `15rem`으로 줄인다.
- 작은 화면에서는 기존처럼 뷰포트 너비를 넘지 않게 제한한다.
- 기본 확장 상태, 접기 기능, 드래그 기능과 링크 순서는 유지한다.

## 변경하지 않는 범위

- 경력, 교육, 연락처의 문구와 링크
- 3D TV의 모델, 모션과 캔버스 크기
- 순택이 오버레이의 크기와 위치
- 한 페이지 구조, 바닐라 JavaScript 모듈, GitHub Pages 호환 방식

## 검증 기준

- `--paper`가 `#fefefe`이며 `#ffffff`와 `#000000`을 사용하지 않는다.
- CSS에 `700`을 초과하는 `font-weight`가 없다.
- 첫 화면 이름, 메인 문장과 설명 문장이 승인된 자간·행간·굵기를 사용한다.
- Contact Me의 최대 기본 너비가 `15rem`이다.
- 기존 콘텐츠, 링크, TV와 오버레이 동작 관련 테스트가 계속 통과한다.
