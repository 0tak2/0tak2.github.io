# 포트폴리오 경험 리디자인 설계

## 목표

임영택의 이력과 작업 경험을 한 페이지에 유지하면서, 첫 화면에서 이름과 다음 문장을 가장 강하게 보여준다.

> 상상을 컴파일하는 엔지니어.  
> 기술과 비즈니스의 경계를 넘어  
> 팀의 비전을 실현합니다.

페이지는 기술 자체를 과장하거나 경력을 해설하지 않는다. 예술 이론 전공, 서버 개발, 모바일 교육, 다시 서버 개발로 이어진 사실을 순서대로 배치해 배경과 강점이 자연스럽게 드러나게 한다. 사용자가 제공하지 않은 분류명, 역할명, 의미 부여 문구는 추가하지 않는다.

## 시각 방향

- 배경은 흰색 범주로 제한한다. 베이지색과 장식적인 유색 배경은 사용하지 않는다.
- SUIT 고딕을 기본 서체로 사용해 한국어 가독성을 확보한다.
- 날짜, 링크, TV 화면의 코드처럼 성격이 분명한 짧은 정보에만 monospace를 사용한다.
- 세리프 서체는 사용하지 않는다.
- 섹션은 그림자나 카드 대신 얇은 중립 회색 선과 충분한 여백으로 구분한다.
- 영문은 `YOUNGTAEK LIM`, 고유 링크명, 코드와 기술명처럼 필요한 경우에만 사용한다. 한국어 문장을 영어로 다시 표현하지 않는다.
- 유행하는 터미널 화면이나 자동 생성된 포트폴리오처럼 보이는 장식은 넣지 않는다.

## 페이지 구성

### 첫 화면

첫 화면은 `100svh`를 기준으로 한 화면을 채운다. `임영택`과 `YOUNGTAEK LIM`을 문장보다 앞선 명확한 위치에 두고, 이름·핵심 문장·3D 브라운관 TV를 주요 요소로 사용한다. GitHub, Blog, TIL 링크는 시선을 방해하지 않는 위치에 둔다.

브라운관 TV는 목업의 평면 벡터를 그대로 사용하지 않는다. Three.js의 기본 geometry와 material로 직접 구성한 3D 모델을 사용하며, 별도 3D 모델 파일을 내려받지 않아도 동작하게 한다. 외형은 90년대 한국 가정용 CRT를 기준으로 한다. 은회색의 낮고 두꺼운 사각 플라스틱 본체, 화면 대부분을 차지하는 볼록한 유리, 화면 아래의 작은 물리 버튼 배열과 전원 버튼, 측면 스피커를 사용한다. 안테나, 다리, 상단 다이얼이 있는 더 오래된 수상기 형태는 사용하지 않는다. TV 화면에는 짧은 코드가 CanvasTexture로 렌더링된다.

TV는 페이지 진입 시 화면 밖에서 안으로 들어오고, 사용자가 다음 섹션으로 스크롤하면 화면 밖으로 빠져나간다. 포인터 이동에 작은 회전 반응을 더하되 읽기를 방해하지 않는다. `prefers-reduced-motion: reduce`에서는 진입·퇴장과 포인터 반응을 제거하고 정적인 TV를 보여준다.

### 경력

첫 화면 아래에서 시작한다. 회사별로 기간, 회사명, 기존 역할 설명을 같은 구조로 배치한다.

피피비스튜디오는 다음 내용만 표시한다. 세부 업무, 분류, 표, 빈 자리, 접기 UI를 추가하지 않는다.

- 피피비스튜디오스
- `2026. 03 ~`
- 컬러렌즈 O2O 서버 및 백오피스 풀스택 개발

티맥스 클라우드와 솔트룩스는 현재 `index.html`의 원문을 유지한다. `앱 서버`, `테스트` 같은 새 분류명을 만들지 않는다. 기존 목록의 표현과 순서만 시각적으로 정돈한다.

### 교육

현재 교육 항목을 모두 유지하고 Apple Developer Academy 기간만 종료 시점에 맞게 갱신한다.

- Apple Developer Academy @ POSTECH / Cohort 2025 / `2025. 03 ~ 2025. 12`
- 한국소프트웨어산업협회 기업멤버십 SW캠프 / 기존 기간·설명·수상 내용 유지
- 홍익대학교 / 기존 기간·전공 내용 유지

### 연락처와 외부 링크

하단 연락처에서 위치 정보는 제거하고 `이메일`이라는 라벨과 이메일 주소를 표시한다. Contact Me 오버레이는 기본으로 펼쳐진 상태이며 사용자가 접거나 다시 펼칠 수 있다. 오버레이와 하단 연락처에는 이메일, Instagram(`https://www.instagram.com/0tag2/`), LinkedIn(`https://www.linkedin.com/in/0tag2/`)을 표시한다. 상단의 GitHub, Blog, TIL 링크는 유지한다. 외부 링크는 새 탭에서 열고 `rel="noopener noreferrer"`를 함께 지정한다.

### 순택이 오버레이

사용자가 제공한 순택이 사진 세 장은 각각 독립적으로 드래그할 수 있는 오버레이로 유지한다. 세 번째 사진의 초기 위치는 본문 열을 가리지 않도록 화면 왼쪽 가장자리에 붙인다. 세 오버레이와 Contact Me는 서로 다른 초기 위치를 사용한다.

## 코드 구조

페이지는 정적 한 페이지와 바닐라 JavaScript를 유지한다. 빌드 도구를 추가하지 않고 브라우저 ES module로 나눈다.

- `index.html`: 시맨틱 문서 구조, 실제 콘텐츠, SEO 메타데이터, 모듈 진입점
- `styles.css`: SUIT 서체, 레이아웃, 타이포그래피, 반응형 규칙, 모션 감소 규칙
- `scripts/main.js`: 페이지 초기화와 모듈 연결
- `scripts/tv-scene.js`: Three.js scene, procedural TV 모델, CanvasTexture, 렌더 루프, 크기 변경 처리
- `scripts/tv-motion.js`: 진입·퇴장 스크롤 진행률과 포인터 반응 계산

Three.js는 브라우저 모듈 CDN에서 고정 버전으로 불러온다. Three.js를 불러오지 못하거나 WebGL을 사용할 수 없으면 같은 자리를 비우지 않고 단순한 정적 TV 대체 요소를 표시한다.

## 상호작용과 데이터 흐름

1. `main.js`가 DOM 준비 후 TV 컨테이너를 확인한다.
2. 모션 감소 설정과 WebGL 사용 가능 여부를 판단한다.
3. 사용 가능하면 `tv-scene.js`가 캔버스와 3D TV를 생성한다.
4. `tv-motion.js`가 스크롤 위치와 포인터 위치를 정규화해 장면에 전달한다.
5. 장면은 해당 값으로 TV의 위치와 회전을 보간한다.
6. TV가 화면에서 멀리 벗어나면 렌더링을 멈추고, 다시 보이면 재개한다.

모션과 3D가 실패하더라도 이력과 링크를 포함한 본문은 JavaScript 없이 읽고 사용할 수 있어야 한다.

## 반응형과 접근성

- 넓은 화면에서는 문장과 TV를 균형 잡힌 두 열로 배치한다.
- 작은 화면에서는 이름과 문장 다음에 TV가 오는 한 열 구조를 사용한다.
- 경력 기간은 보조 회색이 아니라 본문과 같은 검정색으로 표시하고, 기존보다 한 단계 큰 크기를 사용한다.
- 시맨틱한 `header`, `main`, `section`, `footer`와 단계가 올바른 제목 구조를 사용한다.
- 캔버스에는 의미를 설명하는 접근 가능한 대체 텍스트를 제공한다.
- 키보드 포커스가 보이도록 하고 링크의 터치 영역을 확보한다.
- 장식 목적의 동작은 `prefers-reduced-motion`을 존중한다.

## SEO와 공유 메타데이터

- 한국어 이름과 역할을 반영한 `title`과 description을 작성한다.
- canonical URL을 `https://0tak2.github.io/`로 지정한다.
- Open Graph와 Twitter Card 메타데이터를 추가한다.
- `Person` JSON-LD에 이름, 영문 이름, URL, GitHub와 Blog 링크를 포함한다.
- 공유 이미지는 저장소 내부의 고정 이미지 경로를 사용하고, 페이지의 흰 배경·이름·브라운관 시각 언어와 맞춘다.
- 본문 콘텐츠는 메타데이터와 일치해야 하며 SEO를 위한 숨김 키워드나 반복 문구를 추가하지 않는다.

## 검증 기준

- 첫 화면에서 이름, 핵심 문장, TV가 스크롤 없이 보인다.
- 첫 스크롤 이후부터 경력, 교육, 연락처가 순서대로 나타난다.
- 피피비스튜디오스에는 회사명, 기간, 역할 한 줄만 있다.
- 기존 티맥스 클라우드, 솔트룩스, 교육, GitHub, Blog, TIL 링크가 보존된다.
- 기술 섹션은 표시하지 않는다.
- 하단 연락처와 기본 확장 상태의 Contact Me에 이메일, Instagram, LinkedIn이 표시된다.
- 세 번째 순택이 오버레이는 초기 상태에서 본문을 가리지 않는다.
- Apple Developer Academy 기간이 `2025. 03 ~ 2025. 12`로 표시된다.
- 데스크톱과 모바일에서 가로 스크롤이나 텍스트 겹침이 없다.
- WebGL 실패 및 모션 감소 환경에서도 내용과 대체 TV가 정상 표시된다.
- 외부 링크가 기존 URL을 유지한다.
- HTML 구조, SEO 메타데이터, 모듈 로딩에 오류가 없다.
